# 주말나들이

전국 주요 지역의 가족 나들이 장소를 현재 위치 또는 직접 고른 출발 지역의 날씨와 공기질에 맞춰 추천하는 모바일 웹앱입니다. 별도 패키지 설치나 API 키 없이 정적 파일로 실행할 수 있습니다.

## 모바일에서 항상 접속하도록 공개 배포 (GitHub Pages)

GitHub Pages는 정적 파일을 GitHub 서버에서 제공하므로 PC를 끄거나 PC가 인터넷에 연결되지 않아도 휴대폰의 인터넷으로 열 수 있습니다. 공개 저장소를 사용하면 앱 소스도 누구나 볼 수 있습니다.

1. 프로젝트 파일을 인터넷에 연결된 기기로 옮깁니다. 이 폴더의 `weekend-outing.zip`을 휴대폰에서 다운로드한 뒤 압축을 풀어도 됩니다.
2. GitHub에 로그인하고 **New repository**를 눌러 공개 저장소를 만듭니다. 예: `weekend-outing`.
3. 저장소 첫 화면의 **Add file → Upload files**를 눌러 압축을 푼 프로젝트 파일을 저장소의 최상위에 올리고 커밋합니다. `index.html`이 저장소 최상위에 있어야 합니다.
4. 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택하고 `main` / `/(root)`를 지정한 뒤 저장합니다.
5. 배포가 완료되면 `https://깃허브아이디.github.io/weekend-outing/` 주소로 휴대폰에서 접속합니다. Safari/Chrome의 공유·메뉴에서 **홈 화면에 추가**를 선택하면 앱처럼 쓸 수 있습니다.

주소가 나오기까지 몇 분 걸릴 수 있습니다. 이후 앱 내용을 바꾸면 같은 저장소에 수정 파일을 커밋하면 사이트가 업데이트됩니다. 날씨와 공기질은 접속/새로고침할 때 Open-Meteo에서 새로 불러오며, 축제 일정은 최신 검색 링크로 확인합니다.

## PC에서 로컬 실행

Python이 설치된 컴퓨터에서 이 폴더를 열고 다음 명령을 실행하세요.

```powershell
python -m http.server 8765
```

로컬 실행은 개발·미리보기 용도입니다. 같은 Wi-Fi의 다른 기기에서 접속할 수 있지만, PC가 꺼지면 접속할 수 없습니다. 화면 위쪽에서 시·도별 출발 지역을 고르면 설정이 기기에 저장됩니다. HTTPS 사이트(또는 localhost)에서 위치 권한을 허용하면 현재 위치로도 바꿀 수 있습니다.

## 포함 기능

- Open-Meteo의 7일 날씨 예보와 최대 5일 공기질 예보를 표시합니다.
- 강수, 기온, 바람, 예상 최대 AQI를 반영해 실내·야외 장소의 추천 순위를 조정합니다.
- 현재 위치 또는 서울·경기·강원·충청·전라·경상·제주 등 17개 출발 지역을 기준으로 날씨와 장소 추천을 바꿉니다.
- 추천 첫 화면에서 7일 날씨와 오전·오후 활동 시간대의 날씨 아이콘, 준비 팁을 확인하고 새로고침할 수 있습니다. 목적지 날씨·공기질은 출발지에서 차량 3시간 이내인 장소만 요청해 불필요한 좌표 요청을 줄입니다. 거리별·다녀온 곳·행사 화면은 하단 메뉴에서 전환하며, 전체 장소 순위는 펼쳐서 볼 수 있습니다.
- 기본 장소는 `app.js`의 목록과 `places-data.js`의 전국 추가 목록(수도권·강원·충청·호남·영남·제주의 박물관·과학관·동물원·수족관·테마파크·공원·해변·유적·시장·거리 등)을 합쳐 약 280곳이며, 지도 서버 연결 없이도 어느 출발지에서나 추천 후보가 충분하도록 했습니다. 장소를 더 넣으려면 `places-data.js`에 같은 형식으로 한 줄씩 추가하면 됩니다.
- 거리별 화면의 **＋ 장소 직접 추가**에서 장소 이름을 검색(OpenStreetMap Nominatim)해 목록에 없는 곳을 추가할 수 있습니다. 추가한 장소는 추천·거리별·코스·실내 대체 장소에 함께 반영되고, 이 기기에 최대 60곳까지 저장되며 기록 백업 파일에 포함됩니다.
- 서울·인천·수원·대구·부산·제주뿐 아니라 세종·청주·천안·춘천·안동·울산·창원·전주·광주·순천 등 지역 중심지의 시장·상점가도 고정 목록에 두어 지도 데이터 연결이 안 될 때도 지역 장소를 추천합니다. 어느 출발지를 선택하더라도 오늘 추천, 전체 순위, 거리별 목록, 실내 대체 장소와 코스 추천을 차량 3시간 이내 장소로 제한하며, 제주와 본토 간 차량 이동은 추천하지 않습니다. 오늘 추천과 거리별 목록에는 관광 명소 외 생활형 장소 유형도 가능한 경우 함께 보여줍니다.
- 출발지·날씨·장소 간 이동 거리를 고려한 1~3곳의 추천 코스를 만들고, 원할 때 내 코스에 추가할 수 있습니다. 추천 코스의 예상 이동 시간에는 출발·복귀 구간도 포함합니다. 직접 코스에 담은 장소는 순서를 바꾸거나 삭제할 수 있으며, 기기 간 자동 동기화는 되지 않습니다. 코스 공유 링크에는 장소·출발 지역·선택 날짜가 담겨, 가족이 링크를 열면 같은 코스를 기기에 저장할 수 있습니다.
- 추천 장소에서 실내 장소만 보기 필터를 사용할 수 있으며, 설정은 해당 기기에 저장됩니다.
- 비·눈·강풍·극단 기온·나쁜 공기질 예보에는 실내 대체 장소를 추천하며, 해당 장소도 코스에 담을 수 있습니다.
- 오늘의 추천은 지역·종류가 겹치지 않도록 6곳을 고르며, 거리별 화면은 시간대마다 최대 20곳을 추천순으로 보여줍니다.
- 추천 화면은 날짜·출발 지역별로 후보 묶음을 바꿔 보여주며, "다른 코스"로 같은 날에도 다른 조합을 둘러볼 수 있습니다. "다녀왔어요"를 누르면 이 기기의 방문 기록과 장소별 표시 횟수가 저장되고, 90일 동안 새 장소보다 뒤로 밀립니다. 다녀온 곳 화면에서 방문 장소·횟수·최근 방문일을 모아보고, 한줄 메모를 남기거나 방금 한 기록을 취소할 수 있습니다. 기록 백업 파일에는 방문 기록·메모·내 코스·가족 인원 설정·직접 추가한 장소가 포함되며, 불러올 때 방문 기록과 직접 추가한 장소는 합치고 코스와 가족 설정은 백업 내용으로 바꿉니다.
- 거리별 장소는 1시간 이내, 1~2시간, 2~3시간의 겹치지 않는 구간으로 나누며, 출발지와 같은 장소·도시의 0분 항목도 1시간 이내에 표시합니다. 이동 시간은 OpenStreetMap의 OSRM 도로망 주행 시간과 도로 거리(km)를 받아, 구간 평균속도로 시내(신호·정체)와 고속도로를 구분해 보정한 뒤 날짜·권역별 혼잡 가중치와 주차·장거리 휴게 여유를 더한 참고치입니다. 모든 장소에 차량 시간과 도로 거리(km)를 함께 표시하며, 도로망 조회에 실패한 장소는 해안·산악 지형을 고려한 추정치를 "약 ○km"로 구분해 보여줍니다. 추천 코스는 출발→장소들→복귀 전체 경로를 도로망으로 다시 조회해 구간별 시간·거리와 총 거리를 표시합니다. 도로망 조회 결과는 출발 위치별로 최대 30일간 저장합니다.
- 상단 **현재 위치** 버튼은 GPS 정밀 위치를 먼저 시도하고(실패 시 네트워크 위치), 그 좌표를 출발지로 삼아 날씨·차량 이동시간·거리를 다시 계산합니다. 동네 이름(예: 현재 위치 · 분당구)을 함께 표시하고 PC 길찾기 검색에도 사용하며, 12시간 동안 기기에 저장해 새로고침해도 유지됩니다. 지역을 다시 고르면 해당 지역 기준으로 돌아갑니다. 이 계산은 실시간 교통량이나 사고 정보를 반영하지 않으므로 실제 경로와 소요 시간은 네이버 길찾기에서 확인해 주세요. 네이버 지도 앱이 있는 모바일 기기에서는 앱 길찾기를 시도하고, 앱을 열 수 없으면 웹 검색으로 연결합니다. PC에서는 네이버 지도 웹으로 연결합니다.
- 수도권·강원·충청·호남·영남·제주도의 가족 나들이 장소를 추가하고 전국 계절 축제, 지도 및 운영정보 검색 링크를 제공합니다. 제주와 본토 간은 차량 이동이 아닌 항공·선박이 필요하므로 차량 거리 추천에서 제외합니다.
- OpenStreetMap에서 출발지 주변 관광지·박물관·전시·동물원·테마파크·공원·역사유적·문화공간·쇼핑몰·시장·보행자거리와 유명 거리, 식당을 유형별로 나눠 탐색합니다. 박물관·동물원·수족관·테마파크는 반경 100km, 공원·유적·시장 등 개수가 많은 유형은 반경 40km에서 찾고 동네 어린이공원·소공원은 제외합니다. 공개 Overpass 서버가 혼잡할 때를 대비해 여러 서버에 동시에 요청하고 먼저 온 응답을 쓰며(최대 1분), 실패해도 기본 장소로 추천은 계속됩니다. 가까운 장소만 무작정 앞에서 자르지 않고 유형별 상한(최대 15곳, 전체 100곳)을 둬 콘텐츠 구성을 고르게 하며, 이름과 유형·좌표를 조합해 중복 장소를 줄입니다. 출발지별 장소 데이터는 7일간 저장하고 필요하면 "지금 새로 찾기"로 갱신할 수 있습니다. 지도 데이터의 등록 수준은 지역마다 달라 누락될 수 있으며 새로 찾은 장소의 운영 여부는 방문 전에 확인해 주세요. 식당은 출발지 반경 10km에서 찾으며, 검색된 식당 중 장소 반경 3km 이내 데이터가 있으면 장소 카드에 표시하고, 모든 장소 및 코스에서 `장소명 주변 맛집` 검색 링크를 제공합니다.
- 선택한 날짜에 맞춰 출발 지역과 차량 3시간 이내 목적지의 날씨·공기질을 비교합니다. 더 먼 장소는 출발지 예보를 참고 정보로 사용합니다.
- 전국 나들이 장소를 날씨·공기질·아이 나이와 출발지 이동시간에 따른 추천 점수순으로 보여줍니다.
- 어른 수, 아이 수, 아이별 만 나이를 바꾸면 추천 순위에 반영하며 설정은 해당 기기에 저장됩니다.
- 계절별 지역 축제를 개최 시기에 맞는 월별로 소개하고, 해당 연도의 최신 일정 검색 링크를 제공합니다.
- 축제 개최일은 해마다 다를 수 있어 고정 날짜로 단정하지 않습니다. 방문 전 검색 결과와 운영기관 안내를 확인해 주세요.
- 날씨·공기질 요청에 제한 시간을 두어 응답이 지연되어도 다시 시도할 수 있도록 안내합니다. 선택한 날짜의 비·기온·바람·공기질에 맞춘 준비 팁도 제공합니다.

날씨 및 공기질 정보는 인터넷 연결이 필요하며, 추천 점수는 참고용입니다.
